# Tackling Failure Modes of PINNs and PIKANs Using Conflict-Free Gradients
JAX implementation of gradient surgery (Norm-PCGrad, PCGrad, ConFIG) and curvature-aware optimization (SSBroyden) for conflict-free training of PINNs and PIKANs in 2D/3D domain decomposition. Benchmarked on Helmholtz, Poisson, and sine-Gordon equations. Code coming soon!
